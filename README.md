# bankruptcy-prediction
Taiwanese Bankruptcy Prediction based on Taiwan Economic Journal dataset from 1999 to 2009

dataset is from: https://archive.ics.uci.edu/dataset/572/taiwanese+bankruptcy+prediction


Chosen features based on correlation with target and eachother:
Persistent EPS in the Last Four Seasons       -0.238
Total debt/Total net worth                     0.219
Non-industry income and expenditure/revenue   -0.205
Net Value Growth Rate                         -0.203
Quick Ratio                                   -0.202
Tax rate (A)                                  -0.158
Cash/Total Assets                             -0.151
Operating Gross Margin                        -0.148
